EVM

성과관리 (SPI·SV)

계획·실적 가중 진척률로 SPI·SV와 누적 S-curve를 자동 계산해 일정 성과를 정량 측정합니다.

CPM

임계경로 분석

선행작업 의존성으로 임계경로와 여유(slack)를 산출하고, 지연 위험 작업을 표에서 강조합니다.

협업

실시간 동기화

클라우드 저장과 SSE 실시간 반영, 낙관적 동시성으로 팀원 변경이 즉시 보입니다. 오프라인 폴백 지원.

팀

역할 기반 권한

소유자·관리자·멤버·뷰어 역할로 프로젝트 접근을 통제합니다. 이메일 초대와 링크 수락.

자동화

CSV · 공개 API

화면 컬럼 계약 그대로 CSV 왕복. 개인 액세스 토큰(PAT)으로 스크립트·CI에서 API 연동.

간트

주간 간트 차트

계획·실적 오버레이로 일정 흐름을 한눈에. WBS 3단계(단계·Activity·Task) 트리 편집.
